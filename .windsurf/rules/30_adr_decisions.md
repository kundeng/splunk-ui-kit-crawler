# Design Decisions / ADRs (Activation: Manual or Model Decision)
1) Create ADRs for architecture choices, schema changes, library adoption, API contracts.
2) ADR format is mandatory; fill Context, Decision, Alternatives, Consequences, Status, Links.
3) Link ADR to related PR/Commit and tickets.
4) When an ADR is superseded: UPDATE Status on both ADRs and cross-link them.
5) Summarize ADR impact into activeContext.md (one bullet) after acceptance.
